    Sync and backup

    Your notes are saved on this device and, once sync is on, in notes.json in your private GitHub repository, where every change is kept in its history. You can also save copies anywhere. Every file opens without this app.

    How to make an access token
    1. On github.com, open Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Name it "Auditory Range" and set the expiration to the longest allowed (or "No expiration").
    3. Under Repository access, choose Only select repositories and pick auditory-range-data.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Generate it, copy it, and paste it above. Use the same token on your phone and your PC.

    The token stays on this device and can only touch your notes repository.
